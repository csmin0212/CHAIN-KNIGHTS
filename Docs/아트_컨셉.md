# 아트 컨셉: 모험가 길드의 서류

> 화면에 나오는 모든 것은 길드가 발행한 문서와 물건.
> 시각 자료: https://claude.ai/artifact/QMhHsr5S5JD9keMEyZ13ns (컨셉, 색·글꼴·무늬, 화면 요소 대응표, 전투 화면 예시)

## 키워드
| 키워드 | 무엇 | 규칙 |
|---|---|---|
| 서류 | 의뢰서, 등록증, 모험 일지 | 정보는 양피지에 잉크로 적는다 |
| 도장 | 확정, 연계, 격파, 완료 | 결정의 순간은 쾅 찍힌다 |
| 황동 | 테두리, 나침반, 사슬 고리 | 장식은 모서리와 핵심 표시에만 |

**길드 문장**: 나침반(모험) + 사슬 고리(체인). 카드 뒷면, 로딩, 길드 홀 바닥에 반복.
"나이츠"는 길드에 등록된 플레이어 파티의 이름. 기사단 문장, 스테인드글라스는 쓰지 않는다.

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| 잉크 차콜 | `#17181F` | 배경 |
| 패널 | `#1F2129` | 패널 안쪽 |
| 패널 밝음 | `#2A2C36` | 빈 칸, 눌림 |
| 황동 | `#C9A96E` | 테두리, 제목 |
| 황동 빛 | `#E6C98A` | 강조, 선택 |
| 황동 어둠 | `#8A6A3A` | 약한 테두리 |
| 양피지 | `#EFE3C8` | 글을 적는 종이 |
| 잉크 | `#3B3226` | 양피지 위 글씨 |
| 봉랍 | `#9B2F25` | 도장, 확정 |

속성 색은 카드 띠와 아이콘에만: 화 `#D9583B` · 빙 `#4C9BD6` · 풍 `#4FA36B` · 광 `#E3B53B` · 암 `#8A72C4`

## 글꼴 (모두 무료 OFL)
- **고운바탕** (Gowun Batang): 제목, 카드 이름, 일지, 양피지 위 글
- **Noto Sans KR**: 수치, 버튼, 상태 표시
- **Cinzel**: 영문 배너와 큰 숫자만 (TURN, CHAIN, BREAK). 로고와 같은 계열

## 무늬
나침반 · 사슬 고리 · 봉랍 · 고무 도장 · 압정 · 접힌 모서리

## 화면 요소 → 길드 물건
| 화면 요소 | 길드 물건 | 연출 |
|---|---|---|
| 출격 준비 | 게시판의 의뢰서 | 압정에 꽂힌 종이. 랭크 도장 (노멀 동 · 레이드 금) |
| 파티 칸 | 모험가 등록증 | 선택을 마치면 초록 봉랍 (`ui_ready_check`) |
| 손패 카드 | 길드 기술 증서 | 황동 테두리 + 속성 띠 + 양피지 효과문. 각성은 금빛 인장 |
| 카드 뒷면 | 길드 봉투 | 공개 순간 한 장씩 뒤집힘 |
| 코스트 | 황동 주화 | 남은 코스트만큼 주화. 고르면 하나씩 빠짐 |
| 신호 | 수신호 메모 | 아군 등록증 옆에 쪽지 (아이콘 + 짧은 말) |
| 적 행동 예고 | 현상수배 꼬리표 | 부위에 압정으로 꽂힘. 전체 공격은 봉랍 테두리 |
| 체인 | "연계" 도장 | 같은 속성 카드 위에 쾅. 사슬 고리로 이어짐 |
| 부위 파괴 | "격파" 도장 | BREAK + 화면 흔들림 + 부위 흐려짐 |
| 전투 기록 | 모험 일지 | 신호는 연필색, 적 행동은 붉은 잉크 |
| 제한 시간 | 황동 회중시계 | 5초 남으면 붉게 |
| 확정 버튼 | 봉랍 도장 | 누르면 찍히는 소리와 함께 눌림 |
| 결과 | 보수 정산서 | 받은 재료와 골드 + "완료" 도장. 패배는 "재도전" |

## 할 것 / 하지 말 것
- 할 것: 정보는 양피지 위 잉크색 글씨 · 결정의 순간은 도장 연출 · 황동 장식은 모서리와 핵심 표시에만 · 속성 색은 띠와 아이콘에만
- 하지 말 것: 네온 빛, 무지개 그라데이션, 유리 광택 · 화면 전체를 황동으로 · 둥근 알약 버튼 남발 · 이모지, 픽셀 아이콘, 다른 화풍 섞기
