# 에셋 목록

## 제작 현황

- 모험가 길드 톤의 그래픽 **PNG 75개**, 사운드 **14개** 제작 완료 (A·B와 C 선택 항목 포함).
- 최종 파일은 `Assets/Resources/Art/`, `Assets/Resources/Audio/`에 있다.
- [제작 내역·전체 미리보기·사용법](Art/guild_assets.md), [파일 검사 결과](Art/guild_delivery_audit.json).
- 제작 완료와 게임 연결 완료는 구분한다. 현재 코드가 읽는 카드·초상화·적·전투 배경 외의 파일은 별도 연결이 필요하다.
- 사운드는 외부 샘플 없이 합성한 초안이며 게임 내 청취·음량 조정은 별도다.


> 체인 나이츠에 필요한 그래픽과 사운드. 위에서부터 먼저 필요한 순서다.
> 코드는 처음에 색칠한 사각형(임시 그래픽)으로 만들고, 에셋이 생기면 같은 이름의 파일로 바꿔 끼운다.

**진행 상황**: A~C는 1차 납품 완료 (`Docs/Art/guild_assets.md`). **새로 필요한 에셋은 D에 적는다.**
그림의 방향은 `Docs/아트_컨셉.md`가 기준이다. 컨셉이 바뀌면 그 문서를 먼저 고치고, 필요한 에셋을 D에 추가한다.

## 공통 규칙

- **형식**: PNG, 배경 투명. 사운드는 WAV(효과음), OGG(배경음악)
- **해상도 기준**: 화면 1920×1080
- **파일 이름**: 영어 소문자와 밑줄 (예: `icon_element_fire.png`)
- **넣는 곳**: `Assets/Resources/Art/<폴더>/` (폴더: `Cards`, `Icons`, `Arthurs`, `Enemies`, `Backgrounds`, `UI`), 사운드는 `Assets/Resources/Audio/`
  - 예: `Assets/Resources/Art/Enemies/enemy_golem.png`
  - 이 이름대로 넣으면 **코드 수정 없이 바로 화면에 나온다.** 없으면 임시 도형이 그대로 나온다.
- **가져오기 설정**: Texture Type을 `Sprite (2D and UI)`로. 늘려 쓰는 틀(카드 틀, 패널)은 Sprite Editor에서 테두리(9-slice)를 잡는다.
- **화풍**: `Docs/아트_컨셉.md` (모험가 길드의 서류). 차콜 바탕 + 황동 테두리 + 양피지 + 봉랍 도장. 색, 글꼴, 무늬, 화면 요소별 대응은 그 문서를 기준으로 한다.
- 무료 에셋을 쓸 때는 **라이선스를 꼭 확인**한다. 공모전에도 내므로 CC0(출처 표시 불필요)가 가장 편하다. 출처 표시가 필요한 에셋은 이 문서 맨 아래에 적어 둔다.

## 직접 만들지 않아도 되는 것

- **한글 폰트**: 고운바탕, Noto Sans KR, Cinzel (무료, OFL 라이선스). 연결은 개발 쪽에서 한다.
- **피해 숫자, 체인 글자, 카드 이름과 설명**: 모두 폰트로 그린다.
- **속성 색 입히기, 카드 조합**: 흰색 계열 원본 하나로 코드에서 처리한다.
